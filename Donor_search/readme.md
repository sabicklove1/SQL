# Проект «Анализ донорской активности DonorSearch»

## Описание и цель проекта
**Проект направлен на комплексный анализ поведения доноров крови в системе DonorSearch. Основная цель — выявление ключевых факторов, влияющих на донорскую активность, и разработка рекомендаций для увеличения количества регулярных донаций**

- Работа с `ProsgreSQL`

## Результаты и выводы
### Региональный анализ
**Вывод: Наибольшее количество доноров сосредоточено в крупных городах (Москва, Санкт-Петербург, Казань), что указывает на необходимость развития донорства в регионах**

### Динамика донаций
**Вывод: Наблюдается сезонность активности доноров с пиками в весенние месяцы и спадом в конце года**

### Эффективность бонусной системы
**Вывод: Бонусная программа с пиццей показывает наилучшие результаты по вовлечению доноров**

### Анализ социальных сетей
**Вывод: Пользователи Яндекс показывают наибольшую среднюю активность донаций, а ВКонтакте является крупнейшим каналом привлечения**

## Ключевые рекомендации
- Развитие региональных программ - усилить маркетинг в регионах с низкой донорской активностью
- Сезонное планирование - проводить дополнительные акции в периоды спада активности (октябрь-ноябрь)
- Оптимизация бонусной системы - расширить популярные бонусные программы и улучшить информирование о них
- Работа с социальными сетями - развивать присутствие в Яндекс и ВКонтакте как наиболее эффективных каналах
- Программы лояльности - внедрить систему поощрений для повторных доноров

**Результаты проекта указывают на потенциал для роста донорского движения через целевые маркетинговые стратегии и оптимизацию программ мотивации**
